# Security

Please report a security problem in SymbolEngine privately, not in a public issue. On GitHub, open the repository's [Security tab](https://github.com/cybra/symbolengine/security) and choose **Report a vulnerability**.

Say what is affected and how to make it happen, with a small example if you can. The conversation stays private until a fix is out, and the fix's release says what it fixed.

Until the first release, only the latest code on `main` is supported.
